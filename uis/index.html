HealthCore

The full public marketing experience now lives in the Next.js app at uis/healthcore. This file is a thin entry so agents and developers do not maintain a second duplicate website.

Run the public site

  1. cd uis/healthcore
  2. npm install
  3. npm run dev → http://localhost:3000

Run the internal backoffice (hiring tracker + welcome)

  1. cd uis/backoffice
  2. npm install
  3. npm run dev → http://localhost:3001
