# HealthCore public website

Next.js + TypeScript public site for HealthCore patients and referring partners.

## Run

```bash
cd uis/healthcore
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Sections

- `/` Home + patient sign-up
- `/doctors` Clinician directory
- `/locations` Clinic locations
- `/services` Services & specialties
- `/costs` Costs & billing
- `/care` Get care now
- `/about` About HealthCore
